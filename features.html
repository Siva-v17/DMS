Everything inside the vault

Features that turn a file dump into a filing system

Every plan starts with the same governed core — search, security, and version control — then layers on the workflow tools your team needs.

Search

Find the clause, not just the file

Full-text OCR runs on every upload, including scanned paper. Search by clause type, party name, expiry date, or custom tag — results rank by relevance across millions of pages in under a second.

  • OCR on every scanned page automatically
  • Clause and entity detection out of the box
  • Saved searches with expiry-date alerts
E-signature

Send, sign, and file — without switching tools

Native e-signature means the signed copy never leaves the vault. Every signature request is tracked, reminded, and versioned automatically, in 14 languages.

  • Multi-party signing with routing order
  • Legally binding, court-tested audit trail
  • Auto-reminders and expiring signing links
